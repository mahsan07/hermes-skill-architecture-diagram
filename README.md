# Hermes Skill: Architecture Diagram

A small, shareable skill package extracted from the Hermes catalog.

## What it does

Create dark, readable SVG architecture diagrams from system descriptions.

## Example

> Create a dark SVG showing a mobile client, API gateway, worker queue, model router, vector store, and audit log.
